K-Means Manual Simulation

Step-by-step manual implementation of the K-Means clustering algorithm.

Dataset Explanation

The dataset consists of 100 records with two numerical features: Training Hours (X) and Calories Burned (Y).

The data is distributed into three natural groups representing low, medium, and high activity levels.

Iterations Process

  • 3 iterations were performed
  • Initial centroids were selected manually
  • Euclidean distance was calculated for each data point
  • Clusters were assigned based on minimum distance
  • Centroids were updated using the mean of each cluster

Distance Calculation

The Euclidean distance formula was used:

d = √((xₚ - x𝑐)² + (yₚ - y𝑐)²)

Distances were calculated between each point and the three centroids.

Cluster Assignment

Each data point was assigned to the nearest centroid using the minimum distance.

The assignment was automated in Excel using comparison functions.

Centroid Updates

New centroids were calculated as the average of all points within each cluster.

After the first iteration, centroids adjusted significantly, and in later iterations they stabilized.

Variance (SSE) Comparison

  • Iteration 1 → SSE = 660,557
  • Iteration 2 → SSE = 307,280
  • Iteration 3 → SSE = 307,280

The SSE decreased significantly between iteration 1 and 2, indicating improved clustering.

Interpretation of Results

The K-Means algorithm successfully grouped the dataset into three clusters.

A significant reduction in SSE between the first and second iteration shows that the model improved cluster compactness.

From iteration 2 onward, the SSE remained constant, indicating that the algorithm reached convergence and the centroids stabilized.

The final clusters represent three distinct levels of activity: low, medium, and high performance.
