K-Means Manual Simulation

Step-by-step manual implementation of the K-Means clustering algorithm.

Dataset Explanation

The dataset consists of 100 records with two numerical features: Training Hours (X) and Calories Burned (Y).

The data is distributed into three natural groups representing low, medium, and high activity levels.

Figure 1. Initial dataset used for K-Means simulation.

Iteration Tables

Three iterations of the K-Means algorithm were performed manually until convergence was reached. Each iteration included distance calculation, cluster assignment, and centroid updates.

Figure 2. Iteration 1 - Distance calculation and cluster assignment.

Figure 3. Iteration 2 - Updated clusters and centroids.

Figure 4. Iteration 3 - Final stable clusters.

Distance Calculation

The Euclidean distance formula was used:

d = √((xₚ - x𝑐)2 + (yₚ - y𝑐)2)

Distances were calculated between each data point and each centroid.

Cluster Assignment

Each data point was assigned to the nearest centroid using the minimum distance.

This process was implemented in Excel using comparison formulas.

Centroid Updates

New centroids were calculated as the mean of all points belonging to each cluster.

After the first iteration, centroids changed significantly, and then gradually stabilized.

Variance (SSE) Comparison

  • Iteration 1 → SSE = 660,557
  • Iteration 2 → SSE = 307,280
  • Iteration 3 → SSE = 307,280

The SSE decreased significantly between iteration 1 and 2, indicating improved clustering quality.

Figure 5. SSE comparison across iterations.

Interpretation of Results

The K-Means algorithm successfully grouped the dataset into three clusters.

The reduction in SSE demonstrates that the clusters became more compact after each iteration.

The algorithm reached convergence in the third iteration, where no further changes in cluster assignments were observed.

The final clusters represent three levels of activity: low, medium, and high performance.
