K-Means Manual Simulation

Step-by-step manual implementation of the K-Means clustering algorithm.

Dataset Explanation

The dataset consists of 100 records with two numerical features: Training Hours (X) and Calories Burned (Y).

The data is distributed into three natural groups representing low, medium, and high activity levels.

This distribution makes the dataset suitable for clustering, as clear group structures can be identified and analyzed.

Figure 1. Initial dataset used for K-Means simulation.

Iteration Tables

Three iterations of the K-Means algorithm were performed manually until convergence was reached.

Each iteration included three key steps: distance calculation, cluster assignment, and centroid update.

This iterative process allows the algorithm to progressively improve cluster quality.

Distance Calculation

The Euclidean distance formula was used to measure similarity between data points and centroids:

d = √((xₚ - x𝑐)2 + (yₚ - y𝑐)2)

This metric determines how close each point is to each centroid. The smaller the distance, the higher the similarity.

This step is essential because it directly influences how clusters are formed.

Cluster Assignment

Each data point was assigned to the nearest centroid based on the minimum distance calculated.

This assignment step defines the structure of clusters and determines which points belong together.

The process was implemented manually in Excel using comparison formulas to identify the closest centroid.

Centroid Updates

New centroids were calculated as the mean of all data points assigned to each cluster.

This step ensures that centroids move toward the center of their respective clusters.

After the first iteration, centroids changed significantly, indicating that the initial positions were not optimal. In later iterations, centroid movement decreased, showing stabilization.

Variance (SSE) Comparison

  • Iteration 1 → SSE = 660,557
  • Iteration 2 → SSE = 307,280
  • Iteration 3 → SSE = 307,280

SSE (Sum of Squared Errors) measures how compact the clusters are.

The significant reduction between iteration 1 and 2 shows that the clustering improved considerably.

Since the value did not change between iteration 2 and 3, convergence was achieved.

Figure 5. SSE comparison across iterations.

Interpretation of Results

The K-Means algorithm successfully grouped the dataset into three clusters.

The reduction in SSE demonstrates that the clusters became more compact and well-defined after each iteration.

The algorithm reached convergence in the third iteration, where no further changes in cluster assignments were observed.

The final clusters represent three distinct activity levels: low, medium, and high performance.

This confirms that K-Means is effective in identifying hidden patterns in unlabeled data.
