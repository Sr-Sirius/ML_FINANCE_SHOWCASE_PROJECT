K-Means Clustering Application

Implementation of unsupervised learning using the K-Means algorithm.

Context of the Data

This dataset represents gym activity, where each record corresponds to a user session. The objective is to group individuals based on their training behavior and identify distinct activity patterns.

Dataset Explanation

  • Number of records: 2000
  • Feature 1: Training Hours per Week (X)
  • Feature 2: Calories Burned per Session (Y)
  • Source: Synthetic dataset generated in CSV format

Data Preprocessing

The dataset was standardized using StandardScaler to normalize feature ranges and improve clustering performance. This prevents variables with larger scales from dominating the model.

Model Training

The K-Means algorithm was applied with K = 3 clusters. The model iteratively assigns data points to the nearest centroid and recalculates centroid positions until convergence is reached.

Interpretation of Results

The K-Means algorithm successfully identified three distinct clusters representing different levels of physical activity.

Cluster 0 corresponds to low activity, Cluster 1 to moderate activity, and Cluster 2 to high activity levels.

The separation of clusters and the position of centroids demonstrate that the model effectively captured underlying patterns in the dataset.

This confirms that unsupervised learning techniques such as K-Means are capable of discovering meaningful structures without labeled data.
