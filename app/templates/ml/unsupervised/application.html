K-Means Clustering Application

Implementation of unsupervised learning using the K-Means algorithm.

Context of the Data

This dataset represents gym activity, where each record corresponds to a user session. The goal is to group individuals based on their training behavior.

Dataset Explanation

  • Number of records: 2000
  • Feature 1: Training Hours per Week (X)
  • Feature 2: Calories Burned per Session (Y)
  • Source: Generated synthetic dataset (CSV file)

Data Preprocessing

The data was standardized using StandardScaler to normalize the feature ranges before applying the K-Means algorithm.

Model Training

The K-Means algorithm was applied with K = 3 clusters. The model iteratively assigns points and updates centroids until convergence is reached.

Interpretation of Results

The model successfully grouped the data into three clusters representing different levels of physical activity.

Cluster 0 corresponds to low activity, Cluster 1 to medium, and Cluster 2 to high activity levels.

The centroids represent the average behavior of each group, confirming that the algorithm identified meaningful patterns in the dataset.
