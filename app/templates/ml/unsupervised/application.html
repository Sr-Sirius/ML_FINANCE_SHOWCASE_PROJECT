K-Means Clustering Application

Implementation of unsupervised learning using the K-Means algorithm.

Context of the Data

This dataset represents gym activity, where each record corresponds to a user session.

The objective is to group individuals based on their training behavior in order to identify patterns such as low, medium, and high activity users.

This type of analysis is commonly used in fitness applications and health platforms to personalize recommendations and improve user engagement.

Dataset Explanation

  • Number of records: 2000
  • Feature 1: Training Hours per Week (X)
  • Feature 2: Calories Burned per Session (Y)
  • Source: Synthetic dataset generated in CSV format

The dataset is sufficiently large to allow meaningful clustering, and both features are continuous numerical variables suitable for distance-based algorithms.

Data Preprocessing

The dataset was standardized using StandardScaler to normalize feature ranges.

This step is crucial because K-Means relies on distance calculations, and variables with larger scales could otherwise dominate the clustering process.

Normalization ensures that both features contribute equally to the model.

Model Training

The K-Means algorithm was applied with K = 3 clusters, assuming three distinct activity levels.

The model iteratively assigns data points to the nearest centroid and recalculates centroid positions until convergence is reached.

This process minimizes the intra-cluster variance (SSE), improving the compactness and separation of clusters.

Interpretation of Results

The K-Means algorithm successfully identified three distinct clusters representing different levels of physical activity.

Cluster 0 corresponds to low activity, Cluster 1 to moderate activity, and Cluster 2 to high activity levels.

The separation of clusters and the distribution of centroids indicate that the model effectively captured patterns in user behavior.

Additionally, the clustering results demonstrate how unsupervised learning can provide valuable insights without requiring labeled data.

This approach can be applied in real-world systems to segment users, optimize recommendations, and improve decision-making processes.
