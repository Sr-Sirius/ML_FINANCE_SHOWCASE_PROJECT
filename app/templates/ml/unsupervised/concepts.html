K-Means — Unsupervised Learning Concepts

Understanding how machines find patterns without labeled data.

What is Unsupervised Learning?

Unsupervised learning is a type of machine learning where the model works with data that has no labeled outputs. The goal is to identify patterns, structures, or relationships within the data.

Clustering

Clustering is the process of grouping similar data points together. Each group is called a cluster.

K-Means Algorithm

  • Select K initial centroids
  • Assign each point to the nearest centroid
  • Recalculate centroids (average)
  • Repeat until convergence

Centroids

A centroid represents the center of a cluster and is calculated as the average of all points belonging to that cluster.

Euclidean Distance

The distance between two points is calculated using:

d = √((x₁ - x₂)2 + (y₁ - y₂)2)

Iterative Process

K-Means works iteratively. Each iteration improves cluster assignments until the centroids no longer change.

Convergence

Convergence occurs when cluster assignments no longer change or when the centroids stabilize between iterations. At this point, the algorithm stops.

Variance (SSE)

SSE (Sum of Squared Errors) measures how close points are to their centroid. Lower values indicate better clustering.

Real-World Applications

  • Customer segmentation
  • Market analysis
  • Fraud detection
  • Image compression
  • Anomaly detection
