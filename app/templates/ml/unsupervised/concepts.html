Basic Concepts - Unsupervised Learning

What is Unsupervised Learning?

Unsupervised learning finds patterns in data without labeled outputs.

Clustering

Grouping similar data points together.

K-Means

Algorithm that divides data into K clusters using centroids.

Centroids

Average position of points in a cluster.

Distance (Euclidean)

d = √((x₁ - x₂)² + (y₁ - y₂)²)

Iterative Process

  • Assign points
  • Update centroids
  • Repeat

Variance (SSE)

Sum of squared distances to centroids.

Applications

  • Customer segmentation
  • Market analysis
  • Anomaly detection
